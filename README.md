# 2026_07_29_gdp_display_git_module_info
Tools to generate a text file in your project containing information about the main Git repository and addon submodules, making it easier for users to locate and access your source code.

Not a git client.

It just read the Git file in your project when in the editor to create information about the project commit id and submodule information.
